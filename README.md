# Radar Eleitoral 2026 — Protótipo visual

Primeira versão visual do painel do Radar Eleitoral 2026, construída para validar layout, hierarquia de informação e experiência antes da integração com os dados reais do TSE.

## Importante
Os candidatos, percentuais e números exibidos são **dados de demonstração**. Não representam resultados reais.

## Estrutura
- `index.html` — painel
- `styles.css` — identidade visual e responsividade
- `app.js` — dados demonstrativos e interações básicas
